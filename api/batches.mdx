A cultivation batch represents a single grow run — a named record linking a mushroom species, a start date, a Pico unit, and optionally a growing recipe that defines the target environmental conditions. The Batches API lets you create and track batches programmatically so you can correlate sensor data with specific grows, record notes, mark runs complete, and maintain a full cultivation history without touching the dashboard.

---

## GET /api/batches

Returns an array of all cultivation batches.

### Request

```bash
curl -H "Authorization: Bearer <your-token>" \
     http://<pi-ip>:3000/api/batches
```

### Response `200 OK`

```json
[
  {
    "id": "batch-001",
    "name": "January Oysters",
    "species": "Pleurotus ostreatus",
    "startDate": "2025-01-01T00:00:00Z",
    "status": "active",
    "unitId": "pico-01",
    "recipeId": "recipe-oyster-standard"
  }
]
```

<ResponseField name="id" type="string">
  Unique identifier for the batch.
</ResponseField>

<ResponseField name="name" type="string">
  Human-readable name for this cultivation run.
</ResponseField>

<ResponseField name="species" type="string">
  Mushroom species being cultivated in this batch.
</ResponseField>

<ResponseField name="startDate" type="string (ISO 8601)">
  The date and time the batch was started.
</ResponseField>

<ResponseField name="status" type="string">
  Current lifecycle state of the batch. One of `"active"` or `"complete"`.
</ResponseField>

<ResponseField name="unitId" type="string">
  The Pico unit assigned to monitor and control this batch.
</ResponseField>

<ResponseField name="recipeId" type="string | null">
  The growing recipe applied to this batch, or `null` if no recipe is assigned.
</ResponseField>

## POST /api/batches

Creates a new cultivation batch.

### Request Body

<ParamField body="name" type="string" required>
  A descriptive name for the batch (for example, `"January Oysters"`).
</ParamField>

<ParamField body="species" type="string" required>
  The mushroom species being cultivated (for example, `"Pleurotus ostreatus"`).
</ParamField>

<ParamField body="startDate" type="string (ISO 8601)" required>
  The date and time the batch begins. Provide in ISO 8601 UTC format.
</ParamField>

<ParamField body="unitId" type="string" required>
  The ID of the Pico unit that will monitor this batch.
</ParamField>

<ParamField body="recipeId" type="string">
  Optional. The ID of the growing recipe to apply. If omitted, no automated condition targets are set.
</ParamField>

<ParamField body="notes" type="string">
  Optional. Free-text notes for this batch (inoculation details, substrate composition, observations, etc.).
</ParamField>

### Request

```bash
curl -X POST \
  -H "Authorization: Bearer <your-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "January Oysters",
    "species": "Pleurotus ostreatus",
    "startDate": "2025-01-01T00:00:00Z",
    "unitId": "pico-01",
    "recipeId": "recipe-oyster-standard",
    "notes": "5% bran supplemented hardwood substrate."
  }' \
  http://<pi-ip>:3000/api/batches
```

### Response `201 Created`

Returns the newly created batch object.

```json
{
  "id": "batch-001",
  "name": "January Oysters",
  "species": "Pleurotus ostreatus",
  "startDate": "2025-01-01T00:00:00Z",
  "status": "active",
  "unitId": "pico-01",
  "recipeId": "recipe-oyster-standard",
  "notes": "5% bran supplemented hardwood substrate."
}
```

## PATCH /api/batches/:id

Partially updates an existing batch. Use this endpoint to mark a batch complete, append notes, swap the assigned recipe, or correct any field.

### Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier of the batch to update.
</ParamField>

### Request Body

Send only the fields you want to change. All fields are optional.

<ParamField body="name" type="string">
  Updated display name.
</ParamField>

<ParamField body="status" type="string">
  Updated lifecycle status. Set to `"complete"` to close out a batch.
</ParamField>

<ParamField body="recipeId" type="string">
  Assign or change the growing recipe.
</ParamField>

<ParamField body="notes" type="string">
  Updated notes. Replaces the existing notes value.
</ParamField>

### Request

```bash
curl -X PATCH \
  -H "Authorization: Bearer <your-token>" \
  -H "Content-Type: application/json" \
  -d '{"status": "complete", "notes": "Harvested 340g first flush."}' \
  http://<pi-ip>:3000/api/batches/batch-001
```

### Response `200 OK`

Returns the updated batch object.

## DELETE /api/batches/:id

Permanently deletes a batch record. Associated sensor readings are not deleted.

### Path Parameters

<ParamField path="id" type="string" required>
  The unique identifier of the batch to delete.
</ParamField>

### Request

```bash
curl -X DELETE \
  -H "Authorization: Bearer <your-token>" \
  http://<pi-ip>:3000/api/batches/batch-001
```

### Response `200 OK`

Returns an empty body or a confirmation object on successful deletion.

The Settings API exposes the system-wide configuration that governs how Mushroom Pi behaves — the temperature unit displayed in the dashboard, how many days of sensor readings to retain before pruning, and other operational preferences. You can read the current settings to inspect your installation's configuration, or update individual fields without touching the dashboard.

---

## GET /api/settings

Returns the current system settings as a single object.

### Request

```bash
curl -H "Authorization: Bearer <your-token>" \
     http://<pi-ip>:3000/api/settings
```

### Response `200 OK`

```json
{
  "temperatureUnit": "C",
  "dataRetentionDays": 30,
  "pollingIntervalSeconds": 60
}
```

<ResponseField name="temperatureUnit" type="string">
  Unit used to display temperature readings across the dashboard and API responses. `"C"` for Celsius, `"F"` for Fahrenheit.
</ResponseField>

<ResponseField name="dataRetentionDays" type="integer">
  Number of days for which sensor readings are retained in the SQLite database before being pruned. Set to `0` to disable automatic pruning.
</ResponseField>

<ResponseField name="pollingIntervalSeconds" type="integer">
  How frequently (in seconds) the backend polls each registered Pico unit. Default is `60`.
</ResponseField>

---

## PATCH /api/settings

Updates one or more system settings. Send only the fields you want to change — omitted fields retain their current values.

### Request Body

<ParamField body="temperatureUnit" type="string">
  Set the display temperature unit. Accepted values: `"C"` (Celsius) or `"F"` (Fahrenheit).
</ParamField>

<ParamField body="dataRetentionDays" type="integer">
  Number of days to retain sensor readings. Set to `0` to keep readings indefinitely.
</ParamField>

<ParamField body="pollingIntervalSeconds" type="integer">
  Polling frequency in seconds. Lower values increase data resolution but add load to both the backend and the Pico units.
</ParamField>

### Request

```bash
curl -X PATCH \
  -H "Authorization: Bearer <your-token>" \
  -H "Content-Type: application/json" \
  -d '{"temperatureUnit": "F", "dataRetentionDays": 90}' \
  http://<pi-ip>:3000/api/settings
```

### Response `200 OK`

Returns the full settings object reflecting the updated values.

```json
{
  "temperatureUnit": "F",
  "dataRetentionDays": 90,
  "pollingIntervalSeconds": 60
}
```

<Note>
  Changes to `pollingIntervalSeconds` take effect on the next scheduler tick. The backend does not require a restart. Changes to `temperatureUnit` are cosmetic at the API level — raw readings are always stored and returned in Celsius; conversion is applied at display time.
</Note>

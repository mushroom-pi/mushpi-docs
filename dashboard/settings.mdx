The Settings page has a single control: the **display timezone**.

## The display timezone

The **Timezone** field sets how dates and times are shown across the dashboard — on the Dashboard's last-seen ages, the batches' start and finish dates, and the readings. It changes how things are displayed, not how they are stored. Choose your timezone and click **Save**.

## Where the other things live

Several things a grower might expect to find here are elsewhere — either on a unit's own page or in the server's configuration, not in the dashboard UI.

| You might be looking for | Where it actually is |
|---|---|
| Rename a unit, edit its description, face colour, or whether it is monitored | The unit's own page — open the unit from **Pico Units** and use **Edit** |
| How long readings are kept | Server configuration: the `READINGS_RETENTION_MONTHS` environment variable, default six months. See [Environment configuration](/deployment/environment) |
| How often units are polled | Fixed on the server at one reading per minute — it is not a dashboard setting |
| How the control loop responds to targets | [Hysteresis control](/configuration/hysteresis-control) |

This is step 2 of a grow. A **batch** is one grow on one unit — from start date to finish date, on a single Pico unit. Every grow you run gets its own batch record.

## Start a batch

1. Click **Batches** in the sidebar.
2. Click **New Batch** in the top-right of the page.
3. In the dialog, work through the fields:

| Field | What it is |
|---|---|
| **Unit** | The Pico unit that runs this grow |
| **Recipe** | Optional — pre-fills the targets below |
| **Description** | A short label for the batch |
| **Start** | When the grow begins |
| **Finish** | When it ends |
| **Species** | What you are growing |
| **Temperature Target (°C)** | The temperature to hold |
| **Humidity Target (%)** | The humidity to hold |
| **Notes** | Free text, optional |

4. Click **Save**.

### Choosing the unit and recipe

The **Unit** dropdown lists your monitored units. A unit runs one batch at a time: if the unit you pick already has an in-progress batch, the new batch can only start after that one finishes.

When you select a **Recipe**, the dialog copies the recipe's species and temperature and humidity targets into the form, and sets the **Finish** date to the **Start** date plus the recipe's **Duration (days)**. You can then override any of them for this batch — changing them here does not change the recipe, and the batch keeps its own copy of the targets.

### The finish date

The **Finish** date is computed from the recipe's duration when you pick a recipe and a start date. You can edit it by hand afterwards. A batch's status is worked out from its dates, not stored by you.

## Batch status

| Status | When |
|---|---|
| **Planned** | The start date is still in the future |
| **In Progress** | The batch has started and has not finished |
| **Finished** | The finish date has passed |

The Batches list has a **status filter** so you can show only Planned, In Progress, or Finished batches. It also shows the species, start date and unit for each batch at a glance.

## Edit or delete a batch

Open a batch from the list to see its unit, description, species, targets, start and finish dates, and the recipe it was created from (if any). From there you can **Edit** or **Delete** it. The recipe is chosen at creation only — editing a batch does not let you swap its recipe.
